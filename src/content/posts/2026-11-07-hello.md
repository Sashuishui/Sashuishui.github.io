博客搭好了，用的是 Astro，主题是手写的，只做了基本的东西：文章列表、标签分类、暗色模式、RSS。

## 写一篇新文章

在 `Blog` 目录下打开终端：

```bash
npm run new "今天的标题" --tags 随笔,读书
```

它会在 `src/content/posts/` 下生成一个以当天日期命名的 Markdown 文件，同时在 `public/images/2026-11-07/` 建好了放图的文件夹。

## 加图片

把图片拖进上一步生成的文件夹里，然后在正文里写：

```markdown
![这是一句图注](/images/2026-11-07/screenshot.png)
```

图片会自动按容器宽度缩放，圆角和间距都处理好了，不用手动调尺寸。

## 预览和发布

```bash
npm run dev   # 本地预览，改完存盘网页自动刷新
npm run pub   # 发布：commit + push，GitHub 自动部署
```

## 标签从哪来

文章开头那段 `---` 之间叫 frontmatter，`tags: [随笔, 读书]` 里的词就是标签。标签页和每篇文章底部的标签会自动生成，不用去别处登记。

想改动博客的标题、简介、导航，编辑 `src/config.ts` 就好。
